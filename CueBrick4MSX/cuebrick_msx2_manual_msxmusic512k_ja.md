# キューブリック MSX2版 取扱説明書 — MSX-MUSIC 512KB版

2026-10-05 · ToughkidCST

## このゲームについて

キューブリック（CUE BRICK）は、ブロックを押してレールをつなぎ、ボールにボード上のすべてのレールを通らせるパズルです。このROMは、1989年のアーケードゲームをMSX2に移植した非公式のファン移植版です。

この説明書は **MSX-MUSIC 512KB版**（`cuebrick_msx2_opll.rom`）を扱います。

- 101ステージ: 20グループ × 5面 + FINAL
- モードは3つ: 練習、プレイ、登録（パスワードで続きから）
- 音楽はMSX-MUSIC（FM）、効果音はPSG
- 512KBのROM 1本にすべて収まっているので、512KBまでしか対応しないフラッシュカートリッジでも動きます

原作アーケードゲーム CUE BRICK © 1989 KONAMI。このMSX2版はコナミとは関係ありません。

## 動作環境とROM

MSX2、MSX2+、turbo Rで動きます。VRAM 128KBと、60Hzを表示できる画面が必要です。

| 項目 | 内容 |
| --- | --- |
| ROMファイル | `cuebrick_msx2_opll.rom` |
| サイズ | 512KB（8KBバンク × 64） |
| マッパー | ASCII8 |
| 音楽 | MSX-MUSIC — 本体内蔵、またはFM-PAC |
| 効果音 | 本体のPSG |

MSX-MUSICがない場合は、音楽なしで効果音だけが鳴ります。ゲームはそのまま遊べます。

## 起動のしかた

ROMをフラッシュカートリッジかエミュレータに読み込み、マッパーを **ASCII8** に合わせるとすぐに始まります。

- マッパーを自動で判別できないフラッシュカートリッジやエミュレータでは、ASCII8を手動で指定してください。
- MSX-MUSIC内蔵機（MSX2+、turbo Rなど）は、そのまま音楽が鳴ります。
- MSX-MUSICを内蔵していないMSX2では、FM-PACを別のスロットに挿します。

電源を入れたときに機種を調べ、CPUをいちばん速いモードに切り替えます。turbo RはR800、パナソニックのMSX2+（FS-A1FX / WX / WSX）は5.37MHzです。ゲームの速さは同じで、画面を準備する時間だけが短くなります。電源を入れるときに **1** キーを押していると、切り替えません。

## ゲームの始め方とモード

電源を入れると、ロゴに続いてタイトル画面が出ます。**SPACE**（またはジョイスティックのAボタン）を押すと SELECT MODE 画面に進みます。タイトルを10秒ほどそのままにすると、デモプレイと宇宙のシーンが交互に流れます。その間にSPACEを押すとタイトルに戻ります。

### SELECT MODE

カーソルは最初、Bにあります。上下で選び、SPACEで決定します。画面の数字が9から0まで減ると、カーソルのあるモードで始まります。

| モード | 内容 |
| --- | --- |
| A PRACTICE | 練習用の3面（00-01 〜 00-03）を解きます。PLAY TIMEは30秒で、ミスすると同じ面をやり直します。3面をすべて解くか時間がなくなると、オープニングシーンを経て本編の1-1に進みます。 |
| B PLAY | オープニングシーンに続いて1-1から始まります。 |
| C REGISTER | 名前とパスワードを入れて始めます。前回終わった面から続けられます。詳しくは「登録モード・パスワード・コンティニュー」をご覧ください。 |

### 日本版ルールと海外版ルール

アーケード版は、日本版と海外版でパズルとルールが違います。この移植版には両方が入っていて、最初は日本版ルールで始まります。タイトル画面で **SHIFT+F5** を押すと海外版ルールに切り替わり、画面左上にINTと表示されてロゴがオレンジ色になります。もう一度押すと日本版に戻ります。

|  | 日本版（標準） | 海外版（INT） |
| --- | --- | --- |
| パズル | 日本版の配置 | 海外版の配置 |
| ボール停止 | STOP TIME 200。止めている間だけ減ります | HALT 3回。1回あたり約5秒 |
| タイムオーバー後のコンティニュー | HELP — その面の解き方を見せたあと、同じ面を最初から | 止まったところからそのまま続行 |
| ミス後のやり直し | ボードの色が 灰色 → 青 → 黄色 と変わります | 色は変わりません |
| スターアイテム | 日本版の位置（1グループから） | 3グループから |
| 画面表示 | STOP TIME | HI-SCORE、\[H\]×残り回数 |

## 操作

キーボードとジョイスティック（ポート1）を同時に使えます。

| 動作 | キーボード | ジョイスティック |
| --- | --- | --- |
| カーソル移動 | カーソルキー | 方向 |
| ブロックを押す / 決定 | SPACE | Aボタン |
| ボール加速（押している間） | SHIFT、M、N | Bボタン |
| ボール停止 | CTRL、GRAPH、B、またはSPACEとM・N・SHIFTを同時に | A+Bボタン |
| 一時停止 | F1（グループ間のシーンでのみ） | — |
| ルール切り替え（日本版 ↔ 海外版） | SHIFT+F5（タイトル画面でのみ） | — |
| コンティニュー画面で YES / NO を選ぶ | 左右のカーソルキー、SPACEで決定 | 左右、Aボタン |

ボール停止は、日本版ルールでは押すたびに停止と進行が切り替わり、海外版ルールでは1回押すと約5秒間止まります。

## 画面の見方

左がパズルのボード、右が情報表示です。ボードにはレールの描かれたブロックと空きマス（穴）が1つあり、ボールがレールに沿って転がります。

![日本版ルールのプレイ画面](images/play_jp.png)

| 表示 | 意味 |
| --- | --- |
| PLAY TIME | 残り時間（秒）。面が変わっても引き継がれ、面を始めるたびに少しずつ加算されます。 |
| STAGE | グループ番号-面番号。01-01は1グループの最初の面です。 |
| WARPCOUNT | ボールがマスを1つ通るたびに1ずつ減ります。0になるとワープが開きます。 |
| STOP TIME | ボールを止めておける残り量（日本版ルール）。 |
| 1P-SCORE | 得点。 |

海外版ルール（INT）では、STOP TIMEの位置にHI-SCOREが出て、その下に \[H\]×数字 でHALTの残り回数が表示されます。

![海外版ルールのプレイ画面](images/play_int.png)

ボード上で点滅する緑の枠がカーソルで、暗いマスが穴です。

## ルール

### クリアとミス

ボールがボードの**すべてのレールを1回ずつ通ると**クリアです。ボールが通ったレールは消えます。最後のレールを通った瞬間にクリアになるので、そのあとボールが行き止まりのマスに転がってもかまいません。

ボールが次の場所に入るとミスです。

- レールがつながっていないマス
- 穴
- レールのないブロック

ミスするとボールが爆発し、その面を最初からやり直します。ボードとWARPCOUNTは最初の状態に戻り、ボールが1段階遅くなりますが、PLAY TIMEは戻りません。

### ブロックを押す

カーソルをブロックに合わせてSPACEを押すと、カーソルのブロックと穴の間にある**同じ列のブロックすべて**が、穴の方へ1マスずつ動きます。カーソルが穴と同じ横列か縦列にないと押せません。ボールが乗っているブロックも押せて、そのときはボールも一緒に動きます。青緑色の板は固定壁で、動きません。

### ワープ

WARPCOUNTが0になると、ボードの枠と固定壁に黄色い印が現れます。それ以降は、ボールが枠や固定壁から出ると、同じ列の反対側から入ってきます。入ってくるマスにつながるレールがなければミスで、WARPCOUNTが残っているうちに枠から出てもミスです。

### 時間

PLAY TIMEは60秒から始まり、面を始めるたびに、その面のレールの長さに応じた時間が加算されます。残った時間は次の面に持ち越されます。10秒を切ると警告音が鳴り、0になるとTIME OVERに続いてコンティニュー画面が出ます。

### 得点

| 項目 | 得点 |
| --- | --- |
| ボールがマスに入るたび | 50 |
| ステップボーナス（クリア時） | ステージ番号 × 残りステップ × 100。ステップは1回押すたびに1減るので、押す回数が少ないほど大きくなります |
| タイムボーナス（クリア時） | 残り時間 × 100 |

### スターアイテム

面によっては、ボードの1マスの上に星が浮いています。星はブロックではなくその位置に固定されているので、レールのブロックを星の下に押し込み、ボールにそのマスを通らせると取れます。星は色が変わり続け、**ボールが触れた瞬間の色**でごほうびが決まります。

| 色 | ごほうび |
| --- | --- |
| 赤 | BONUS CLEAR — 残りのレールがすべて消え、その面をすぐにクリアします |
| 緑 | BONUS 2000 — 2000点 |
| 青 | TIME +30 — PLAY TIMEに30秒追加 |

赤はごく短い間しか出ず、緑がいちばん長く続きます。

## 登録モード・パスワード・コンティニュー・ゲームオーバー

### コンティニュー

PLAY TIMEが0になると、TIME OVERに続いてコンティニュー画面が出ます。上の RANKING NO. は、そこまで進んだ面で決まる順位です。

![コンティニュー画面](images/continue.png)

左右で YES / NO を選び、SPACEで決定します。

- **YES**: PLAY TIMEを60秒もらって続けます。STOP TIME（海外版はHALT 3回）も元に戻ります。コンティニューの回数に制限はありません。
- **NO**、または数字が9から0まで減る間に選ばないと GAME OVER です。

日本版ルールでは、YES / NO を選ぶ前に **HELP** が流れます。その面を解くカーソルの動きとブロックの押し方をボールなしで見せ、YESを選ぶと同じ面を最初からやり直します。

### 登録モード（C REGISTER）

名前3文字とパスワード4文字を入れます。カーソルキーで文字盤の文字を選んでSPACEで入力し、`<` は1文字消します。

1. **初めてのとき**: 名前を入れ、パスワードは `----` と入れます。NEW PLAYERと表示され、1-1から始まります。
2. **ゲームオーバーになったとき**: 名前と、そのとき遊んでいた面のパスワードが画面に出ます。メモしておいてください。
3. **次に遊ぶとき**: 同じ名前とそのパスワードを入れると、OK - CONTINUEと表示され、その面から続けられます。得点は0から、PLAY TIMEは60秒からです。

![ゲームオーバー時に出る名前とパスワード](images/password.png)

覚えておくこと:

- パスワードは名前と組になっています。名前が違うと、同じパスワードでもPASSWORD ERRORになり、パスワード4文字を入れ直すことになります。
- カートリッジにセーブ機能はありません。パスワードをメモしておかないと続きから遊べません。
- MSX-MUSIC 1MB版やSCC版でもらったパスワードも、そのまま使えます。
- 登録画面は、30秒たつと登録なしで1-1から始まります。
- 登録画面で **M** または **N** を押すと、登録を飛ばしてすぐに1-1から始まります。

### ゲームオーバー

PLAYER 1 / GAME OVER が約5秒表示されたあと、タイトルに戻ります。1秒ほどたつとSPACEで飛ばせます。登録して遊んでいた場合は、そのあとに名前とパスワードが出ます。

## ステージ構成・グループ間のシーン・一時停止

### ステージ構成

本編は **20グループ × 5面 + FINAL = 101面** です。STAGE表示の前の数字がグループ、後ろの数字がそのグループ内の面番号です。面をクリアするとステップボーナスとタイムボーナスが計算され、ブロックが飛んできて次の面のボードを組み立てます。

背景はグループによって6種類あります: 海、山と街、雲、宇宙と地球、深宇宙、紫のトンネル。海ではサメ・エイ・泡が、宇宙では宇宙船が通り過ぎます。512KB版では、背景やシーンが変わるときに絵1枚を読み込むのに0.4〜0.8秒かかります（標準速度の場合）。

### グループ間のシーン

1つのグループの5面をすべて解くと、STAGE CLEAR / CHALLENGE / NEXT STAGE の文字とともにモアイが出てくる短いシーンが流れ、次のグループに進みます。FINALを解くとエンディングです。

### 一時停止

グループ間のシーンで **F1** を押すとゲームが止まります。短い効果音とともに画面中央で白いPAUSEの文字が点滅し、もう一度F1を押すと再開します。

パズルを解いている最中に一時停止はできません。席を外すときは、面を終えてからグループ間のシーンで止めてください。プレイ中に少し考える時間がほしいときは、ボール停止（STOP TIME / HALT）を使います。ボールが止まっている間もPLAY TIMEは減ります。

## コツ

- **まず道筋を読む。** ボールがどのマスへ出ていくかを見て、着く前に次のレールをつないでおきます。
- **ボールがすぐ入るブロックは押さない。** 動いている最中のブロックにはボールが入れず、ミスになります。ブロックが動いている間は、次の押しも受け付けません。
- **ボールの乗ったブロックを押すと、ボールを運べます。** レールが途切れそうなときに、ボールごと別の場所へ連れていく方法です。
- **時間が足りなければ加速、考えたいときは停止。** レールをすべてつなぎ終えたら、加速を押しっぱなしにした方が、タイムボーナスにも次の面に持ち越す時間にも有利です。
- **押す回数が少ないほどステップボーナスが増えます。** グループが進むほど、掛ける数も大きくなります。
- **ワープを計算に入れる。** WARPCOUNTが0になったあとは、枠を越えて反対側のレールにつなげられるので、行き止まりに見える面が解けます。
- **星は色を見てから入る。** 時間が厳しければ青（TIME +30）、難しい面なら赤（BONUS CLEAR）を狙います。ボール停止でタイミングを合わせられます。
- **行き詰まったらHELPを見る。** 日本版ルールでは、時間切れになるとその面の解き方が流れます。
- **初めてなら A PRACTICE から。** 3面で押し方と加速・停止を覚えたあと、本編に続きます。

## 困ったときは

| 症状 | 確認すること |
| --- | --- |
| 画面が出ない、ロゴのあとで止まる、絵が崩れる | マッパーの設定を確認します。このROMはASCII8です。 |
| MSX1で動かない | MSX2以降（VRAM 128KB）が必要です。 |
| 効果音だけで音楽が鳴らない | 本体にMSX-MUSICがない場合です。FM-PACを別のスロットに挿します。openMSXなら `-ext fmpac` を付け、ROMを `-ext` より前に書きます。 |
| デモは動くのに、タイトルでSPACEが効かない | ROMファイルが壊れているか、カートリッジに正しく書き込まれていない可能性があります。ゲームは起動時にROM全体を検査し、内容が違うと入力を受け付けません。ROMを入手し直して、書き込み直してください。ファイルサイズは524,288バイトです。 |
| 画面が流れる、正しく映らない | ゲームは60Hzで画面を出します。60Hzに対応したモニターかテレビを使います。 |
| turbo Rや高速モードのあるMSX2+で動作がおかしい | 電源を入れるときに **1** キーを押していると、CPUを高速モードに切り替えずに始まります。古いROMには SELECT MODE 画面が崩れる問題があったので、最新のROMかどうかも確認してください。 |
| F1を押しても止まらない | 一時停止はグループ間のシーンでのみできます。 |
| パスワードを入れたのに PASSWORD ERROR | 名前3文字が、パスワードをもらったときと同じか確認します。パスワードはその名前にしか合いません。 |


# Space Manbow Enhanced · MSX2

1989년 코나미의 일본판 《Space Manbow》에 **FRS Enhancement v2.0**과 **대우 MSX2 호환 패치**를 함께 적용한 버전입니다. FRS 패치는 조작 반응과 화면 갱신을 개선하고 타이틀에서 난이도를 고를 수 있게 합니다. 대우 패치는 CPC-400과 CPC-400S 등에서 스크롤 중 화면 일부가 한순간 찢어져 보이던 문제를 보정합니다.

## 플레이할 때 달라지는 점

| 항목 | 강화판에서 달라지는 점 |
| --- | --- |
| 시작 난이도 | 타이틀에서 **Normal**(1회차), **Hard**(2회차 상당), **Insane**(8회차 상당)을 선택합니다. 원작의 후속 회차 난이도를 첫 스테이지부터 플레이할 수 있습니다. |
| 기체 조작 | 키보드와 조이스틱 입력을 더 빨리 읽고 기체 이동을 더 정밀하게 처리합니다. FRS에 따르면 원작에서는 입력이 반영되기까지 때때로 100ms 이상 걸렸습니다. |
| 연사와 밸런스 | 발사 속도에 상한을 두어 고속 연사로 일부 보스가 순식간에 쓰러지던 현상과 탄이 몰릴 때의 처리 부담을 줄였습니다. 이에 맞춰 일부 적을 쓰러뜨리는 데 필요한 명중 수도 조정했습니다. |
| 충돌 판정 | CPU 처리 시간에 여유가 있으면 영상 칩의 스프라이트 충돌 검출을 사용해 픽셀 단위로 판정합니다. 2스테이지의 엘리베이터형 적은 오른쪽 끝까지 피격 판정이 닿도록 고쳤습니다. |
| 화면과 소리 | 보스가 공격을 맞으면 고유 색을 유지한 채 번쩍입니다. 1스테이지 보스의 잘못된 색, 기체가 위로 움직일 때 배경이 비치던 두 곳, 일부 하강 효과음의 음높이도 수정했습니다. |
| 컨트롤러 | joyMega의 **START**로 일시정지하거나 게임 오버 화면에서 이어할 수 있습니다. **A + START**로 현재 게임을 중단할 수 있습니다. 키보드의 이어하기 안내도 **F5**로 바로잡았습니다. |

### 일반 MSX2와 터보 기종

FRS는 적과 탄의 처리, 충돌 검사, 팔레트 변경, 음악 재생에 드는 CPU 시간을 줄이고 화면 갱신을 수직 동기에 맞추는 방식을 개선했습니다. 일반 속도의 MSX2에서도 적과 탄이 많은 장면의 감속을 줄입니다. 터보에서는 게임 진행 속도와 화면 분할 시점을 보정해 3·6·8·9스테이지 보스의 애니메이션이 더 부드럽게 보입니다.

BIOS가 CPU 속도 전환 기능(`CHGCPU`)을 제공하는 기종은 부팅 시 터보가 자동으로 켜집니다. 기본 속도로 시작하려면 부팅할 때 **T**를 누르고 있습니다. V9958 영상 칩에서는 로고와 플레이 화면의 위치도 보정했습니다. [FRS v2.0 원문 설명서](FRSv2.TXT)

## 대우 CPC에서 화면이 찢어지던 이유

게임은 화면을 그리는 도중 정해진 가로줄에 도달했다는 신호를 받아 화면 분할을 처리합니다. 일부 대우 BIOS가 그 신호를 게임보다 먼저 읽으면 게임이 한 프레임 동안 전환 시점을 놓칩니다. 스크롤 중 화면 일부가 순간적으로 어긋나 보이는 이유입니다. 통합판은 부팅할 때 해당 BIOS의 처리 코드를 확인하고, 일치하는 기종에서는 게임이 분할 신호를 받을 수 있게 합니다. [대우 보정 소스](integrated/daewoo-frs.asm)

## 알려진 현상

FRS는 1스테이지에서 드물게 포대의 피격 판정이 한 타일 아래로 밀리는 현상이 있습니다. 7스테이지 보스전에서는 CPU 부하가 높을 때 배경 애니메이션이 한 번에 다 갱신되지 않아 그림 일부가 어긋나 보일 수 있습니다. FRS 패치의 전체 변경 내역과 이용·배포 조건은 [원문 설명서](FRSv2.TXT)에 있습니다.
